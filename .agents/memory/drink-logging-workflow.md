---
name: Drink logging workflow
description: Product priority for the daily drink counter's main logging screen.
---

Users usually log drinks from their saved or favorited drinks; creating a new drink is infrequent.

**Why:** the user said they would rarely add new drinks and mostly use saved and favorited drinks.

**How to apply:** Prioritize one-tap access to saved and favorite drinks on the home screen, and keep new-drink creation available but visually secondary.

The existing drink, history, goal, and spending behavior is working well; UI changes should preserve it.

**Why:** the user said the app functionality is working great while asking for a visual and navigation redesign.

**How to apply:** Rearrange screens and controls without changing calculations, stored data, or established actions unless separately requested.

Past-day entries should be editable and removable, and users should be able to add drinks to any earlier calendar day.

**Why:** the user requested full correction and logging controls for previous days, and reported the hidden add action was hard to find.

**How to apply:** Show a clear add action on collapsed past-day rows and weekly day rows; preserve the selected local date while allowing the user to enter the drink time.
