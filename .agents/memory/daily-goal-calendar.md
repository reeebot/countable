---
name: Date-specific drink goals
description: Product scope for daily drink goals and taper planning.
---

Daily goals may be set per local calendar date, overriding the usual daily default. Taper suggestions should reflect recent logged weekday/weekend patterns and let the user choose the target and duration.

Keep today's date-specific goal, current standard-drink total, progress line, and completion percent visible on the main Log counter card. Turn that card maroon/red when the total exceeds the goal.

**Why:** the user asked for this information to remain on the main card after it disappeared during the tab redesign.

**How to apply:** Use the effective local-day goal and existing standard-drink total; keep the full calendar planner in Goals and limit the over-goal color change to the counter card.

Pattern insights should use local drink timestamps and logged amounts over the last 28 complete days. Context tags are optional and user-selected; comparisons need enough tagged and other-tagged days and describe associations, not causes. Keep context tags in the app's local history and include them in exports.

**Why:** the user asked for patterns that can help reduce drinking and chose optional context tags to record possible influences.

**How to apply:** Keep daily goals date-specific and local to the user's calendar. Explain the logged-history basis for taper suggestions and insights, preserve weekend-heavy patterns rather than assuming equal daily intake, and never infer a user's mood or circumstances.
